# Patient-Friendly Abnormality Illustrations

## Purpose
This directory houses educational visual guides used in **Feature 1: Smart X-Ray Analysis**.

## Clinical Context & Presentation
- Rather than presenting raw, intimidating clinical jargon to patients, the application pairs detected abnormalities with intuitive, non-graphic diagrams.
- For example, an illustration demonstrating fluid in the pleural space or a simplified visual contrasting a normal bone with a hairline fissure.
- All artwork must adhere to patient reassurance standards, avoiding graphic or frightening depictions.
- Licensing: Only original or licensed illustrations are permitted.
