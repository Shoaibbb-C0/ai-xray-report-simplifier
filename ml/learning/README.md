# ML Learning & Experiments

## Preserved Foundational Work
This directory contains the initial exploratory scripts and reference materials created during the early project phase:

- `image_basics.py`: Image loading, grayscale conversion, aspect-ratio-preserving padding, NumPy normalization, and tensor batching.
- `simple_cnn.py`: A standard 2D Convolutional Neural Network module built in PyTorch demonstrating convolution, activation, max pooling, flattening, and linear classification.
- `sample_image.png`, `sample_image1.jpg`: Reference local sample images used during exploratory testing.

## Execution
To verify these learning scripts:

```powershell
python ml/learning/image_basics.py
```
