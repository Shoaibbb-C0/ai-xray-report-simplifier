# Anatomical Assets — Body Map

## Purpose
This directory is designated for custom, patient-friendly anatomical artwork and SVG/vector graphics supporting **Feature 2: My X-Ray Map**.

## Asset Specifications
- **Format**: Clean vector graphics (SVG) or high-resolution optimized PNGs with transparent backgrounds.
- **Style**: Minimalist, modern medical aesthetic with clickable interactive anatomical regions (e.g. chest, skull, spine, shoulder, pelvis, extremities).
- **Licensing**: Only original, licensed, or open-source verified anatomical artwork may be added. Do not scrape copyrighted or unverified images.
